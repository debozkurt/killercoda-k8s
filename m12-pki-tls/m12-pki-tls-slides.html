The Common Name does not count

RFC 6125 forbids matching the CN when the cert presents a DNS SAN. cert-manager writes every dnsNames entry into the SANs.

Trust: the client needs the CA
that signed the server

# the client does not recognize the signer curl: (60) SSL certificate problem: unable to get local issuer certificate

Turn verification off

curl -k and insecureSkipVerify accept any cert, including an attacker's.

Distribute the CA bundle

The CA cert is public. Mount it in the client and pass it to the verifier with --cacert.

Do not use a leaf Secret's ca.crt
as the trust anchor

  • cert-manager fills ca.crt with a best guess
  • It can change when the issuer changes
  • It updates only when the leaf renews
  • trust-manager syncs a CA bundle into every namespace
Add the new CA to the bundlethe bundle now holds both CAs
Issue leaf certs from the new CAclients already trust it

The kubelet refreshes mounted Secret files on its periodic sync.

A process that loaded the cert at startup serves the old cert until it reloads. Alert on the served cert's expiry.

ACME issues public certs
after a domain challenge

HTTP-01

Serve a random token at /.well-known/acme-challenge/. This proves control of the web server.

DNS-01

Publish a TXT record. This proves control of the DNS zone and allows wildcards.

Internal traffic uses a private CA. Public traffic uses ACME. An ACME issuer never signs config-api.media.svc.cluster.local, because that name exists only inside the cluster.

Recap

  • Issuance, identity, trust, plus purpose in mTLS. Name the layer first.
  • cert-manager is a reconciliation loop. Climb from Pod events to the issuer.
  • A cert that cannot issue leaves a stuck Pod. Failures that start together share an issuer.
  • Identity is SANs. Trust is the client's CA, distributed apart from the cert.
  • An HTTP error from the server means the server rejects the client. Read its log.

Production thinking

  • Renewal needs a healthy controller, a working issuer, and a reload. What do you alert on, and why does the served cert's expiry beat the renewal loop?
  • You rotate the internal CA. Does the new CA reach every CA bundle first, or do the new leaf certs come first? Why does a bundle with both CAs prevent an outage?
  • A teammate adds --insecure to close a trust ticket. What did that turn off, and which review rule keeps it out?
